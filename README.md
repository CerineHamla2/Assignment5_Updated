# Assignment5_Updated
## Description

This program contains two functions. The first function, `temp_conversion()`, converts temperatures between Celsius, Fahrenheit, and Kelvin. The second function, `dice_roll()`, calculates the probability of rolling a sum greater than or equal to a desired number using 1 to 4 dice.

Both functions include input validation and raise a `ValueError` when invalid values are entered.

## How to Run

1. Run the Python file.
2. For the temperature conversion program, follow the prompts and enter the requested values.
3. For the dice probability program, run the file to see the results of the predefined test cases.

### Example Run 1: Temperature Conversion

```
Enter the temperature value: 329.7
Enter the scale (C, F, K): K
Enter the desired scale  (C, F,K): F
The converted temperature is: 133.79
```

### Example Run 2: Dice Probability

```
2d6 7 Probability: 0.5833
4d6 9 Probability: 0.9452
3d8 22 Probability: 0.0195
1d20 17 Probability: 0.2
6e4 A Error: Invalid dice configuration/desired output value, please enter a valid format.
```
